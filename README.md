
# 🔧 IoT-Based Machine Monitoring System for Drilling Machine

## 📌 Overview

This project presents an **IoT-based retrofitting solution** for a conventional drilling machine to enable real-time monitoring of machine health parameters such as **temperature, vibration, and position**.
The system helps in **predictive maintenance, fault detection, and reducing machine downtime** without modifying the mechanical structure.

---

## 🚀 Key Features

* Real-time monitoring of machine condition
* Wireless data transmission using ESP32
* Live dashboard visualization
* Industrial IoT architecture
* Low-cost and scalable solution
* Data-driven predictive maintenance

---

## 🛠️ Technologies Used

* ESP32 Microcontroller
* Embedded Systems & IoT
* InfluxDB (Time-series database)
* Grafana (Visualization)
* HTML, CSS, JavaScript
* Arduino IDE

---


## 🔌 Hardware Components

* MPU6050 – Vibration and motion monitoring
* DS18B20 – Temperature sensing
* HC-SR04 – Distance and position monitoring
* ESP32 – Wireless communication and control

---

## 📊 System Architecture

1. Sensors collect machine condition data.
2. ESP32 processes and transmits the data via Wi-Fi.
3. Data is stored in InfluxDB.
4. Grafana visualizes real-time and historical data.
5. Custom dashboard enables remote monitoring.
